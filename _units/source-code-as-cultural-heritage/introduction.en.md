This lesson introduces you to the technique of applying source criticism methods to code, teaching you to view it as both a technical and cultural artefact. In methodological terms, the lesson focuses on three key skills – contextual analysis, critical evaluation and comparative assessment – rather than technical mastery. However, understanding code as a historical source does require engaging with its technical dimensions; learners will be guided toward accessible resources to build this foundational knowledge alongside their critical skills. Although designed for beginners, some exercises require basic digital skills and familiarity with academic research practices.

### More about the lesson
<!-- section-contents -->

In this lesson, you will explore three key dimensions that can help you consider code as heritage:

1. Heritage recognition: The first part examines what qualities make source code a distinctive type of born-digital heritage. This includes understanding how UNESCO recognises it and exploring the unique preservation challenges it presents.
2. Interpretive methods: In the second part and third parts, we develop strategies for reading and interpreting code that go beyond its technical functionality. We approach code as a cultural artefact that reveals important insights about its creators’ assumptions, values and practices. Through detailed case studies, we explore how the traditional tools of source criticism are adapted for born-digital materials, connecting our analysis to broader questions related to digital history and critical code studies.
3. **Preservation initiatives:** Finally, we examine how source code is being preserved through major international initiatives: the GitHub Archive Program, the Internet Archive Software Collection and Software Heritage. Comparing these approaches shows how different preservation strategies address different aspects of code as heritage.

Each section includes practical exercises designed to develop critical thinking about digital sources rather than technical programming skills. By the end of this lesson, learners should be familiar with how to approach source code as historians, recognising its value as historical evidence.
